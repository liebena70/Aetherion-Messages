# Aetherion-Messages
Anonymous Messages Sender for Aetherion
Overview

A web-based anonymous messaging platform developed for the 13th Cohort of SMA Unggul Del. The application allows users to submit appreciation, feedback, and personal messages anonymously through a simple and accessible interface.

The project was built as an exploration of web application development and user-centered design while providing a dedicated communication platform for a school community.

Objectives
Develop a complete web application using PHP and front-end technologies.
Design an intuitive interface for anonymous message submission.
Create a lightweight platform that can be easily deployed and maintained.
Explore how technology can facilitate community interaction and communication.
Features
Anonymous message submission
Simple and responsive user interface
Organized message management
Lightweight web architecture
Easy deployment on standard PHP hosting

PHP
HTML

JavaScript
